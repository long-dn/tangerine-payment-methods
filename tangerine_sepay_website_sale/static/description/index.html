SePay on Website

Let eCommerce customers pay their order by scanning a SePay VietQR code. The order is confirmed and paid as soon as SePay reports the transfer.

Features

QR code on the order confirmation
After checkout, the customer scans a SePay VietQR code with the exact amount and the order reference.
Automatic confirmation
When SePay reports the transfer, the online transaction is completed, the order confirmed and the payment reconciled with the bank statement.

I. Requirements

Odoo 20

In Odoo 20 the order confirmation shows the wire-transfer instructions of the payment app, whose QR code SePay Integration already provides. This module is installed automatically with the shop and SePay Integration and keeps upgrades from Odoo 19 clean.

Install and configure SePay Integration first, then enable the Wire Transfer payment provider on your website, with the bank journal linked to your SePay account.

II. Checkout

The customer chooses SePay (or Wire Transfer) and presses Pay now.

The confirmation page shows the SePay QR code to scan in any Vietnamese banking app.

The transfer then appears in Invoicing > Banking > SePay Transactions as processed, linked to the order and its payment.
